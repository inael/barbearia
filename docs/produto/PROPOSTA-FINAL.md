# Proposta final, Barbearia

## Decisão: modelo de 3% (rev-share) DESCARTADO
Motivo (Inael, 2026-07-28): a construção leva ~30 dias, então o 1º ano já cai pra ~11 meses; e a barbearia é nova, vai demorar pra colocar a operação pra rodar e gerar receita. Ou seja, os 3% no começo incidiriam sobre ~zero (talvez só os últimos ~6 meses gerassem algo). Não compensa. Fica o modelo tradicional com desconto.

## Modelo final (tradicional com desconto)
| | Valor |
|---|---:|
| Valor do sistema completo (6 módulos, com assinaturas) | R$ 8.300 |
| (-) Permuta: 1 ano de corte (R$ 200 × 12) | - R$ 2.400 |
| (-) Desconto especial | - R$ 2.800 |
| **Cliente paga** | **R$ 3.100** |

- Pagamento: **parcelável em até 10x no cartão via Asaas** (~R$ 310/parcela).
- **Sem percentual** sobre o faturamento; o sistema é 100% do cliente.
- **Mensalidade de manutenção: R$ 350/mês** (a partir do go-live), cobre manutenção + hospedagem + WhatsApp (SimplesZap R$59) + IA + email. Custo real ~R$160-190, ver `CUSTOS-OPERACIONAIS.md`.
- Evoluções/novos módulos (VP3): por hora (R$ 120/h) ou orçamento à parte.

Desconto visível pro cliente: sistema de R$ 8.300 saindo por R$ 3.100 (abatimento total de R$ 5.200 entre permuta e desconto).
