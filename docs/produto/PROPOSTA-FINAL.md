# Proposta final, Barbearia

## Decisão: modelo de 3% (rev-share) DESCARTADO
Motivo (Inael, 2026-07-28): a construção leva ~30 dias, então o 1º ano cai pra ~11 meses; e a barbearia é nova, demora pra colocar a operação pra rodar e gerar receita. Os 3% no começo incidiriam sobre ~zero (talvez só os últimos ~6 meses gerassem algo). Não compensa. Fica o modelo tradicional, enquadrando o abatimento como **módulos incluídos sem custo** (não como "desconto").

## Modelo final
| | Valor |
|---|---:|
| Valor do sistema completo (6 módulos) | R$ 8.300 |
| (-) Módulos incluídos sem custo (Assinaturas + Painel do Dono/Caixa) | - R$ 2.400 |
| (-) Permuta: 1 ano de corte (R$ 200 × 12) | - R$ 2.400 |
| **Cliente paga** | **R$ 3.500** |

- Nota interna: Assinaturas (R$1.800) + Painel/Caixa (R$700) valem R$2.500 na tabela; consideramos ~R$2.400 de cortesia pra fechar em R$3.500 (piso que o Inael pediu; ~R$100 a favor).
- Pagamento: **parcelável em até 10x no cartão via Asaas** (~R$ 350/parcela).
- **Sem percentual** sobre o faturamento; o sistema é 100% do cliente.
- **Mensalidade de manutenção: R$ 350/mês** (a partir do go-live): manutenção + hospedagem + WhatsApp (SimplesZap R$59) + IA + email. Custo real ~R$160-190 (ver `CUSTOS-OPERACIONAIS.md`).
- Evoluções/novos módulos (VP3): por hora (R$ 120/h) ou orçamento à parte.
